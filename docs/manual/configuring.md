# Configuring

Because `finix` comes with so little options enabled by default, it is recommended to import and enable one or more profiles for your system, which contain recipes for building a fully usable `finix` system for a variety of use cases.

> [!NOTE]
> This page is a stub. If you have something you would like to contribute, feel free to open a PR and add any documentation for configuring services, programs, or low level system components.
