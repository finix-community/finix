finit.services.<name>.exec-stop Link copied!

Some services may require alternate methods to be stopped. If exec-stop is defined it is preferred over SIGTERM. Similar to exec-reload, finit sets $MAINPID.

Note

exec-stop is called as PID 1, without any timeout! Meaning, it is up to you to ensure the script is not blocking for seconds at a time or never terminates.

Type
null or main program, path or command
Default
null
